#  Random Password Generator

## Project Description

This project is a simple Random Password Generator built using Python. It allows users to generate strong and secure passwords of any desired length.

The program uses Python's built-in `random` and `string` modules to create passwords containing:

- Uppercase Letters (A-Z)
- Lowercase Letters (a-z)
- Numbers (0-9)
- Special Characters (!, @, #, $, %, etc.)

---

## Features

- User chooses password length.
- Generates a strong random password.
- Uses letters, numbers, and symbols.
- Input validation.
- Option to generate multiple passwords.
- Beginner-friendly Python project.

---

## Technologies Used

- Python 3
- random module
- string module

---

## How to Run

1. Install Python 3.
2. Save the file as:

```
random_password_generator.py
```

3. Open Terminal or Command Prompt.

4. Navigate to the project folder.

5. Run the program:

```bash
python random_password_generator.py
```
