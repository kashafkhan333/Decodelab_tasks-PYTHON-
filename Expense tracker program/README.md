# Expense Tracker

## Project Description

Expense Tracker is a simple Python program that allows users to record their daily expenses and calculates the total amount spent. It is a beginner-friendly project that demonstrates the use of variables, loops, lists, user input, and basic mathematical operations.

---

## Features

- Add multiple expenses
- Store expenses in a list
- Calculate the total amount spent
- Display all entered expenses
- Handle invalid input using exception handling
- Easy to understand and beginner-friendly

---

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the project folder.
4. Open a terminal or command prompt.
5. Run the following command:

```bash
python expense_tracker.py
```
